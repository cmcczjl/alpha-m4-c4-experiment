# Crypto Moving Average Crossover Strategy

## 背景
移动平均线（MA）交叉是最经典的趋势跟随策略之一。  
- **短期均线**（如 7‑day SMA）快速响应价格变化。  
- **长期均线**（如 30‑day SMA）平滑噪声，代表整体趋势。

当短期均线上穿长期均线时，视为**买入信号**（多头），反之则为**卖出信号**（空头）。该策略在趋势明显的行情中表现较好，能够在震荡市中减少频繁开仓的风险——这正是我们过去的教训所指向的方向。

## 关键假设
1. **趋势存在**：在过去的 1‑2 个月内，BTC/USDT、ETH/USDT 等主流币种会出现可辨识的趋势段落。  
2. **均线周期**：7‑day SMA 与 30‑day SMA 是经验值，可在后续回测中调参。  
3. **交易成本**：假设每笔交易的手续费为 0.1%（常见的中心化交易所费率），对策略收益的影响在可接受范围内。  

## 具体实现思路
1. **数据获取**：使用 CoinGecko 免费 API 拉取最近 90 天的每日收盘价。  
2. **计算均线**：  
   - `short_ma = SMA(close, 7)`  
   - `long_ma = SMA(close, 30)`  
3. **生成信号**：  
   - `buy_signal = (short_ma[-2] <= long_ma[-2]) and (short_ma[-1] > long_ma[-1])`  
   - `sell_signal = (short_ma[-2] >= long_ma[-2]) and (short_ma[-1] < long_ma[-1])`  
4. **执行逻辑**（示例）：  
   - 当出现买入信号且当前持仓为 0，使用全部可用资金买入 BTC。  
   - 当出现卖出信号且持有 BTC，全部卖出转为 USDT。  

## 风险与限制
- **震荡市**：均线交叉会产生频繁的买卖信号，导致交易成本侵蚀收益。  
- **数据延迟**：CoinGecko 提供的是日线数据，无法捕捉更细粒度的波动。  
- **资金规模**：当前本金仅 $1,000，单笔交易的波动风险较高，需要严格的仓位管理（如 100% 仓位或分批建仓）。
