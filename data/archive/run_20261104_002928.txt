## 4. 最小可交付服务（MVP）范围
1. **信息抓取**：实现对美国 Amazon、eBay、欧洲 Shopify、东南亚 Shopee 四大平台的商品信息抓取（标题、价格、库存、图片）。
2. **数据清洗**：统一货币为 USD，统一时间戳为 UTC，去除重复记录。
3. **差价检测**：提供跨平台同类商品的价格差异报告，阈值默认 15%。
4. **决策示例**：基于阈值自动生成“采购建议” CSV（商品 ID、目标平台、建议采购量、预计利润）。
5. **执行原型**：生成下单脚本（模拟下单）并记录日志。
6. **监控**：通过 Grafana 仪表盘展示抓取成功率、差价检测数量、异常告警。

> **交付形式**：  
> - 代码仓库（GitHub）  
> - Docker Compose 部署脚本（`docker-compose.yml`）  
> - 使用手册（`README.md`）  
> - API 文档（OpenAPI 3.0 JSON）
